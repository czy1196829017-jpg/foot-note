FOOT NOTE — 网页交互原型（v48 · 从登录页开始）

打开后直接显示登录页。选择一种登录方式并完成演示登录，即进入地图和其他功能。
手机号入口需要填写符合格式的11位手机号；也可选择 WeChat / QQ / Apple 演示入口，勾选提示后进入。
这些入口均为本地演示，不会发送验证码或登录真实第三方账号。

Windows 预览：
1. 先完整解压 ZIP 文件，不要在压缩包内直接运行。
2. 双击“启动预览.bat”。浏览器将打开 http://localhost:8787/ 。
3. 预览时保留命令窗口；关闭窗口即停止本地服务。
4. 如系统询问脚本是否运行，请在确认文件来源后允许。

其他系统：
如果已安装 Python 3，在 site 文件夹内打开终端，运行：
python3 -m http.server 8787 --bind 127.0.0.1
随后用浏览器打开 http://localhost:8787/ 。

说明：
- site 文件夹是可部署的完整静态网站，可交给前端开发人员或上传至静态网站托管服务。
- 请通过本地服务预览。直接双击 HTML 文件时，浏览器可能阻止矢量地图数据加载。
- 相机需要浏览器授权，且取决于设备摄像头是否可用。
- 手账、设置等交互数据保存在各自浏览器内，不会随 ZIP 共享。
- 本项目为交互原型，不包含真实账号登录服务或云端 AI 后端。
- 地图数据与素材随包附带；外部字体等联网资源的可用性取决于网络环境。
